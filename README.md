# Image_Generation
Text to Image Generation using n8n

This project is an automated Text-to-Image generation workflow built with n8n.
It takes a text prompt as input and generates an AI-powered image using an image generation model/API.

#🚀 Features

Text prompt → AI image generation

Fully automated n8n workflow

Easy to customize prompts & parameters

Reusable and scalable

API-based integration

#🛠 Tech Stack

n8n

AI Image Generation API (Stable Diffusion / SDXL compatible)

HTTP Request & JSON handling

#⚙️ How It Works

Input text prompt

Workflow sends prompt to image generation API

AI generates the image

Image output is returned (URL / Binary)
